
# NIST CSF 2.0 — Outcome Selection and Evidence Mapping

**Company:** Cedar Ridge Services  
**Assessment:** Small Business Cybersecurity Gap Assessment  
**Scope:** 20 selected NIST CSF 2.0 subcategories  
**Assessment Status:** Planning

## 1. Purpose

This document identifies cybersecurity outcomes relevant to Cedar Ridge Services, a fictional 50-employee IT services company.

The selected outcomes will guide the review of company policies, security practices, and supporting evidence.

The assessment covers all six NIST CSF 2.0 functions but does not evaluate the entire framework.

## 2. Selected CSF Outcomes

### GOVERN (GV)

| CSF ID | Assessment Focus | Evidence to Request |
|---|---|---|
| GV.RR-02 | Define and communicate cybersecurity roles and responsibilities | IT organization chart, responsibility matrix, job descriptions |
| GV.PO-01 | Establish and communicate cybersecurity risk management policy | Approved security policy, employee acknowledgment records |
| GV.PO-02 | Review and update cybersecurity policies when needed | Policy revision history, review schedule, approval records |

### IDENTIFY (ID)

| CSF ID | Assessment Focus | Evidence to Request |
|---|---|---|
| ID.AM-01 | Maintain an inventory of company-managed hardware | Laptop and device inventory, asset ownership records |
| ID.AM-02 | Maintain an inventory of software, cloud services, and systems | Application inventory, approved cloud services list |
| ID.RA-01 | Identify, validate, and document vulnerabilities | Vulnerability scan summary, vulnerability tracking records |
| ID.RA-05 | Evaluate risks using threats, vulnerabilities, likelihood, and impact | Risk assessment methodology, sample risk evaluation |

### PROTECT (PR)

| CSF ID | Assessment Focus | Evidence to Request |

| CSF ID | Assessment Focus | Evidence to Request |

## 3. Selection Rationale

These 20 outcomes were selected based on Cedar Ridge Services' business environment and cybersecurity risks.

The company depends on cloud applications, employee identities, software development systems, and client information.

The selected outcomes emphasize security governance, asset visibility, access control, vulnerability management, monitoring, incident handling, and recovery.

The assessment is intentionally limited to a manageable set of outcomes suitable for a small organization with limited IT and security resources.

## 4. Assessment Boundaries

This document identifies what will be evaluated and the evidence needed.

It does not establish whether the company currently achieves each outcome.

Current implementation, evidence sufficiency, identified gaps, and target practices will be evaluated in later assessment stages.
